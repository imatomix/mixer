# Security Policy

mixer and its modules handle HTTP requests, file serving, cookies, and sessions, so security reports are taken seriously.

## Supported versions

Security fixes are released for the latest version of each package (`@imatomix/mixer` and `@imatomix/mix-*`).

## Reporting a vulnerability

**Please do not report security vulnerabilities through public issues, pull requests, or discussions.**

Report them privately through GitHub's private vulnerability reporting:

1. Go to the [Security tab](https://github.com/imatomix/mixer/security) of this repository.
2. Click **Report a vulnerability**.
3. Describe the issue, including the affected package and version, steps to reproduce (a minimal example or request is ideal), and the impact you expect.

## What to expect

- You will receive an acknowledgement as soon as possible, usually within a week.
- The report will be investigated, and you will be kept informed about the progress and the planned fix.
- Once a fix is released, a security advisory will be published. You will be credited in the advisory unless you prefer to stay anonymous.

Please keep the details private until a fix has been released.
